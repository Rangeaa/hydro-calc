# Гидравлический калькулятор (Python)

Консольная программа для базовых гидравлических расчётов: быстро прикинуть усилие цилиндра, подачу насоса или скорость масла в трубе.

## Что умеет

- **Гидроцилиндр**: усилие и скорость штока при выдвижении и втягивании (с учётом диаметра штока).
- **Насос**: подача по рабочему объёму и оборотам, мощность на валу.
- **Трубопровод**: скорость потока масла и сравнение с ориентировочным диапазоном для всасывающей, сливной и напорной линий.

## Запуск

Нужен Python 3.8 или новее, сторонние библиотеки не требуются.

```
python hydro_calc.py
```

Пример работы:

```

2 - Насос

0 - Выход

Скорость втягивания: 28.3 мм/с
```

## Формулы

| Расчёт | Формула |
|---|---|
| Площадь поршня | A = π · D² / 4 (при втягивании: π · (D² − d²) / 4) |
| Усилие на штоке | F = p · A |
| Скорость штока | v = Q / A |
| Подача насоса | Q = V · n · η_об / 1000 (л/мин) |
| Мощность насоса | P = Q · p / (600 · η) (кВт, Q в л/мин, p в барах) |
| Скорость в трубе | v = Q / A |

Диапазоны скоростей в трубопроводах ориентировочные. Для реальных проектов их нужно сверять с каталогами производителей и нормативной документацией.
